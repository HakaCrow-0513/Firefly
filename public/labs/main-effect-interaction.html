交互作用存在 （两条线不平行：交叉 / 收拢 / 发散）

交互作用存在时，A、B 主效应的四种组合都可能出现：

新教师 b1老教师 b2

交互作用不存在 （两条线平行或重合）

交互作用不存在时，A、B 主效应同样有四种组合：

新教师 b1老教师 b2
核心结论：交互作用是否显著，与主效应是否显著没有必然联系——无论交互作用存在与否，「A、B 主效应均存在 / 仅 A 存在 / 均不存在 / 仅 B 存在」四种情况都可能出现。

图形三步法 （中点法：先看交互 → 判 B → 判 A）

顺序很关键：先判交互作用，再分别用「中点法」判两个主效应。

第 1 步 ｜先看交互作用

看两条线是否交叉，或是否有趋势（收拢 / 发散，即两线斜率不同、不平行）：
平行（含重合） → 交互作用不存在；交叉或有趋势 → 交互作用存在。

第 2 步 ｜B 主效应 —— 看「图例」

按图例对应到每条线，找每条线的线段中点，看中点的纵坐标：
两线中点纵坐标一致 → B 无主效应；不一致 → B 存在主效应。

第 3 步 ｜A 主效应 —— 看「横轴」

在横轴 a1、a2 处分别作垂线，每条垂线与两条线各交于一点，取这两个交点的中点（截距中点），再看它的纵坐标：
a1 处中点与 a2 处中点纵坐标一致 → A 无主效应；不一致 → A 存在主效应。

为什么可以看「中点」？线段中点的纵坐标 = 该线两个数据点的平均；垂线上两个交点中点的纵坐标 = 该水平下两组数据的平均。所以「中点法」与「比较边缘平均数」是同一件事的两种说法——图上看中点高低，等于算平均值。

第 1 步 ｜交互作用 —— 横/竖相减比较 （图：两线斜率／是否平行）

每行做差：D₁ = a1b1 − a1b2，D₂ = a2b1 − a2b2（竖向做差同理），比较两个差值：
有差异 → 交互作用存在；无差异 → 不存在。「差异的差异」就是交互作用。

第 2 步 ｜B 主效应 —— 竖向相加比较 （图例 B：两条线的线段中点）

每列求和：Y₁ = a1b1 + a2b1，Y₂ = a1b2 + a2b2：
有差异 → B 存在主效应；无差异 → 不存在。

第 3 步 ｜A 主效应 —— 横向相加比较 （横轴 A：a1、a2 两处截距中点）

每行求和：X₁ = a1b1 + a1b2，X₂ = a2b1 + a2b2：
有差异 → A 存在主效应；无差异 → 不存在。

图 ↔ 表 对照（同一事实的两种看法）：行和 X₁ 与 X₂ 的比较 ＝ 图上 a1、a2 两处截距中点高低的比较；列和 Y₁ 与 Y₂ 的比较 ＝ 两条线线段中点高低的比较；行差 D₁ 与 D₂ 的比较 ＝ 两条线斜率的比较（是否平行、相交或有相交趋势）。给图用中点法，给表用和差法，结论完全一致。

示范：图 + 表 双视角判读

b1 新教师：a1=5 → a2=9；b2 老教师：a1=7 → a2=7（纵轴 0–15）

线段中点（判 B） 线段中点（判 B） 截距中点（判 A） 纵坐标辅助线

图形法（中点法）：① 两线斜率 4 与 0，不平行 → 交互作用存在；② 两线线段中点纵坐标 7 与 7，一致 → B 主效应不存在；③ a1 截距中点 6 与 a2 截距中点 8，不一致 → A 主效应存在。

表格法（和差法）：① 行差 D₁=−2 与 D₂=2，有差异 → 交互作用存在；② 列和 Y₁=14 与 Y₂=14，无差异 → B 主效应不存在；③ 行和 X₁=12 与 X₂=16，有差异 → A 主效应存在。

两种判法结论完全一致——考场上给图就用中点法，给数据表就用和差法。
