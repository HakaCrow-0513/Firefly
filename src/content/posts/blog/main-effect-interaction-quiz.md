> 摘要：复习「主效应」与「交互作用」最容易踩的坑，是以为「交互作用显著 ⟺ 主效应显著」。两者其实没有必然联系：在交互作用**存在**与**不存在**两种情形下，「A、B 主效应均存在 / 仅 A 存在 / 均不存在 / 仅 B 存在」四种组合都各有一套图例，合起来共 8 张图。这个页面把它们摆在一起，可以边看边拖、边判边测。

## 页面里有什么

- **知识回顾**：交互作用存在（交叉 / 收拢 / 发散）与不存在（平行 / 重合）各 4 张图。每张图下方自动标出「A 主效应 / B 主效应 / 交互作用」各自是否显著，并给出原始数值。
- **判读方法**：图形三步法（**中点法**）与表格三步法（**和差法**）逐条对照，配一张带标注的示范图与 2×2 数据表；页末给出「图 ↔ 表」的等价关系。
- **绘图练习**：拖动图上的圆点 / 方块、直接在图上点击，或改右侧 2×2 表里的数——四条线段由你决定，页面按两种口径实时判读；八种情况有快捷预设，一键摆出。
- **自测练习**：8 道看图判断（A 主效应 / B 主效应 / 交互作用各选「存在 / 不存在」）+ 4 道概念题，自动判分并给出错题回顾。

## 三个判读口径（图与表是同一件事）

1. **交互作用 —— 看两条线是否平行**：交叉、收拢、发散都属于「不平行」→ 交互作用存在；平行（含完全重合）→ 不存在。
2. **B 主效应 —— 看「图例」**：找每条线的**线段中点**，比较纵坐标；两个中点一致 → B 无主效应。
3. **A 主效应 —— 看「横轴」**：在 a1、a2 处分别作**垂线**，取该处两条线交点的**中点（截距中点）**，比较纵坐标；两处中点一致 → A 无主效应。

同一件事换成数据表：线段中点就是「该条线在两个水平上的平均」，截距中点就是「该水平上两条线的平均」；于是「竖 / 横相加比较」判主效应，「横 / 竖相减比较（差异的差异）」判交互作用——**给图用中点法、给表用和差法，结论完全一致**。
