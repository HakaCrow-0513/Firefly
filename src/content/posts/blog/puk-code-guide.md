手机重启后突然弹出PIN码输入框，可自己明明没设置过ｷｬｰ(((;ﾟдﾟ)))ｷｬｰ……别担心，这是手机对SIM卡的保护机制发力了。如果确实没有设置过PIN码，建议根据以下步骤进行验证解锁。
# 一、检验是否为默认PIN码
通常默认的PIN码为『1234』或者『123456』（少数的可能为『0000』），建议先尝试一下这几个默认的PIN码。
如果这三次都显示错误，那么手机的SIM卡就会被锁住(￣ω￣;)，这时候还有10次输入PUK码进行解锁的机会。（o(><；)o🚨千万不要随便尝试，因为PUK码输错10次就会给手机卡销号了）
**不过别担心，虽然PIN码是无法查询的，但是PUK码的查询却有很多方式₍₍ (ง ˙ω˙)ว ⁾⁾**
# 二、查询PUK码的办法
## 移动
1. **拨打人工客服电话，要求查询PUK码**（最推荐）
   这是最简单的查询方式，只需要一个电话就行，但是得注意，人工客服工作的时间为8：00-23：00。（视频客服工作时间为8：00-22：00）
2. 如果不想打电话，也行，那么点击智能客服，输入『PUK码』，然后便会有一个跳转按钮，直接点击就可以进入PUK码的查询
   当然这里会要求输入一个服务号码，通常是在办卡的时候设置的，我想大部分人可能会设置常用的消费密码或者重要的日子之类的，可以先简单尝试一下，实在不行，建议等到客服上班的时候，直接打电话寻求帮助。
3. 最后，如果家里离营业厅比较近，那么也可以直接带着身份证去营业厅寻求线下帮助。
**另外，有很多的其他的办法，例如，公众号、短信查询，视频客服等，其实最终还是需要与人工客服进行沟通，所以不如直接询问人工客服来得方便**
## 联通
与移动不同，联通有着更简单的查询机制。只需要在首页检索PUK码查询即可跳出对应的查询页面。如果之前设置过安全验证则还需要通过安全验证才可以查看PUK码
但是如果这里也不行呢，那依旧是建议拨打人工客服进行查询，这是目前在没有办法的情况下最节省时间和精力的方式

# 最后三千万
千万千万千万要记住，找回后，一定一定记得要记下PIN码和PUK码，最好是在手机和其他设备的笔记或者备忘录里进行记录，博主就是几次都忘记了，结果半夜睡觉都不是那么舒服了。
